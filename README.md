# Customer Churn Analysis using Excel

## Project Overview

This project analyzes customer churn data using Microsoft Excel. The dataset contains customer demographic information, service details, contract information, billing information, and churn status.

The project focuses on preparing the data, creating additional analysis columns, exploring churn patterns, and identifying factors associated with customer churn.

## Objective

The main objectives of this project are:

* Analyze customer churn using Excel
* Understand customer and service characteristics
* Prepare and organize the dataset for analysis
* Create additional categories using Excel formulas
* Analyze churn across different customer segments
* Identify patterns related to contracts, charges, and customer tenure
* Present important findings from the analysis

## Tools & Technologies

* **Microsoft Excel**
* Excel formulas
* Data analysis
* Data visualization

The dataset contains customer-level information including:

## Excel Analysis

Additional columns were created to support the analysis.

### Charges Group

Customer charges were categorized into groups based on their total charges.

Categories include:

* 0-20
* 20-40
* 40-60
* 60-80
* 80+

### Tenure Group

Customer tenure was categorized into different groups.

Categories include:

* 0-12 months
* 12-24 months
* 24-36 months
* 36-48 months
* 48-60 months
* 60+ months

## Analysis Performed

The project analyzes customer churn across different factors, including:

* Contract type
* Monthly charges
* Total charges
* Customer tenure
* Internet service
* Payment method
* Customer services
* Demographic characteristics

## Key Insights

The analysis identified several important churn patterns:

* Customers with **month-to-month contracts** show higher churn compared with customers on longer-term contracts.
* Customers with **higher monthly charges** show increased churn.
* Customer tenure can be used to identify different churn patterns across customer groups.
* Contract and billing characteristics are important factors when analyzing customer churn.
